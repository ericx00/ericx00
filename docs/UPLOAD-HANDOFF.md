| Cute & Cozy UI SFX (Case Portman) | £4.99 | 200+ recorded UI sounds |
| Medieval RPG SFX (AHTu20) | $4.99 | 1,400+ sounds |
| **Forge Pixel VFX + SFX** | **$3** | 37 animations x 6 colours = 222 effects, 111 sounds |
| **Forge Card & Forge SFX** | **$3** | 268 synthesised sounds made for card games |

Where ours is stronger: every effect ships with its sound and a JSON description; the SFX set covers card-game actions other packs skip.
Where ours is weaker: fewer unique animations than ByteWright (37 vs 109), generated instead of hand-drawn, and big libraries have far more sounds per dollar.
At $3 with a generous free version each, that is fair value. It would not be at $8.
