# assetforge

Procedural game asset packs (Python stdlib): Retro SFX, Pixel Sprites, Pixel UI Kit ($8 each, $18 bundle on Whop) + a free starter pack. Also the Forge Deckbuilder Kit + free Deckbuilder Starter (`python3 -m assetforge deck`; TTF fonts need fonttools at build time; price not set by the owner yet). Build: `python3 -m assetforge build`. Tests: `python3 -m unittest discover -s tests -t .`. Benchmark against itch.io top sellers in the same category.

## Rule for every session: always offer value for money

Every product here is sold to real people. Before building, changing, pricing or launching anything:

1. **Benchmark first.** Find what buyers already get from competitors, both free and paid (search their store pages and listings). Write down the comparison.
2. **Free must match free.** Our free tier (or free sample) must be at least as useful as what established free alternatives give.
3. **Paid must clearly beat free.** Every paid feature or pack must offer something buyers cannot get for free elsewhere, at or below the going price. If it does not, improve the product before selling it, or lower the price.
4. **Prove it, do not claim it.** Run the tests, render and look at previews, measure (audio levels, file counts, sizes). Never advertise a number or feature the build does not actually deliver.
5. **Be honest about limits.** State what is untested or weaker than competitors, in the README and to the owner.
6. **Delivery must work on purchase.** Never make a product visible on a store unless buying it delivers the promised files or access.
7. **Keep prices as the owner set them** unless the owner approves a change; give a recommendation with reasons instead.
